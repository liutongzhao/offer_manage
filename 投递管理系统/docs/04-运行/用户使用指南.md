## 一、快速上手：服务启动

日常只需启动前后端两个服务（MinIO 是常驻 docker 容器，一般一直在跑，不用管）：

```bash
# 1. 后端（终端 1）
cd 投递管理系统/backend && source .venv/bin/activate
uvicorn app.main:app --host 0.0.0.0 --port 5112

# 2. 前端（终端 2）
cd 投递管理系统/frontend
npm run dev        # 浏览器打开 http://localhost:5111
```

只有当 MinIO 容器确实没在跑（附件上传/预览报错）时才需要：

```bash
docker start offer-minio    # 容器名 offer-minio，端口 9000-9001
```

> 提示：让小铜罩帮你启动也可以，说一句「启动系统」即可。

## 二、你最常用的方式：对话下令

### 2.1 发起一次投递（核心流程）

在对话里告诉我，格式随意，信息越全越好：

> 「投 字节跳动 Java 后端（后端开发），链接是 https://… ，JD 我发你截图」

**我会自动完成**：
1. 在 `后端开发/字节跳动/投递1_20260904/` 建归档文件夹（按你投的类型自动归类）
2. 从资料库「简历」目录复制初始简历 `柳铜罩简历.pdf`，做针对性修改后放入
3. 系统里建档：公司、投递记录（岗位/类型/渠道/城市/链接/标签）
4. 你给的 JD 截图、投递链接、简历全部上传归档到这条投递下
5. 时间线自动记一条「创建投递」事件

**你给素材的三种方式**：直接发文件/截图给我；发链接让我抓取；说路径我自己读。**投递链接、JD 截图、简历**是最常见的三类，系统对这三类做了重点支持（拖拽上传、图片灯箱预览、多链接管理）。

> **界面操作等价入口**：新增投递抽屉底部有「投递材料」分组，可当场选择已有简历（或上传新简历）、添加 JD 截图等附件（可标类型），保存投递时自动归档。详情页的「简历」卡片支持事后关联/解除关联简历。

### 2.2 状态有进展时

> 「字节的笔试过了，进一面了」
> 「阿里发 offer 了，25k×15」
> 「腾讯挂了」

我会更新投递状态；**每次状态或关键字段变更，系统自动在时间线留痕**（原值 → 新值 + 时间），之后随时可回溯全过程。

### 2.3 沟通记录

> 「昨天字节 HR 加我微信约了一面，周三下午 3 点」

我记一条沟通记录（对象/方式/内容/发生时间）。**沟通时间可以指定过去的时间**（比如"昨天"），不会失真。

### 2.4 遇到问题

> 「这道手撕题记一下：…」（我会录入问题记录并关联对应投递，方便面试前复盘）

### 2.5 随时查

> 「我现在投了几家了？」「哪些快到截止时间了？」「导出一份全部投递的表格」

统计、待办、导出都可以直接问我要。

## 三、页面功能一览（9 个页面）

打开 http://localhost:5111 ，左侧导航分 5 组：

### 📊 投递看板（首页）
- 顶部统计卡片：总投递数、本周新增、面试中、已 Offer、整体转化率
- 投递列表默认按时间倒序，状态标签**就地可改**（点开下拉直接换状态，自动留痕）
- 支持**列表 / 看板双视图**切换；看板按状态分列，**拖拽卡片即改状态**

### 📋 投递记录
- 多条件筛选栏：类型 / 状态 / 渠道 / 城市 / 标签 / 关键词（公司名、岗位模糊匹配），可组合
- 工具栏：**导出 CSV**（Excel 打开中文不乱码）、**导入 CSV**（校验并报告错误行）、行内快速改状态
- 点任意一行进**投递详情页**

### 🔍 投递详情（溯源核心页）
- 左侧：投递全字段信息 + 标签 + 多链接（一键打开、可标记失效）
- 中间**时间线**：创建、状态变更、沟通记录按时间倒序混排；字段变更类事件默认折叠成一行摘要，点开展开看原值/新值
- 新增沟通记录时可自定义发生时间
- 素材区：附件墙（JD 截图/简历/笔试/offer/聊天记录/证明），拖拽多文件上传，图片点击灯箱放大
- 底部：该投递关联的问题记录

### ⏰ 待办提醒
- 基于 deadline 自动生成：**7 天内截止** / **已过期**两组
- 一键跳转对应投递详情

### 🏢 公司管理
- 公司增删改查 + 每家公司的投递数聚合
- 点公司看详情抽屉（含该公司全部投递）

### 📄 简历资产
- 所有上传过的简历列表，初始简历有金色描边星标
- 预签名 URL 在线预览 / 下载

### 🐛 问题记录
- 面试/笔试/流程问题全量记录，支持按分类筛选、关联投递

### 📈 数据统计
- 转化漏斗（投递→笔试→面试→Offer）
- 时间趋势折线图（按周/月投递量）
- 状态分布饼图

### ⚙️ 数据与设置
- **备份**：一键备份数据库到 MinIO，带时间戳
- **恢复**：从备份恢复（需输入确认文字，防误触）
- **导入**：CSV 批量导入投递
- **标签管理**：统一维护标签
- **回收站**：软删除的投递在这里，可恢复

## 四、数据安全

| 机制 | 说明 |
| --- | --- |
| 状态留痕 | 所有字段变更自动记录，不可篡改，随时回溯 |
| 软删除 | 删除先进回收站，可恢复 |
| 备份 | 建议每周说一次「备份一下系统」，我备份到 MinIO |
| 双存储 | 结构化数据在 SQLite，文件在 MinIO，互不干扰 |

**⚠️ 唯一要注意**：`投递管理系统/minio-data/` 是 MinIO 的数据目录，`backend/app/data/` 是数据库目录——**不要手动删改这两个目录**。

## 五、常见问题

**Q：页面打开是空白？**
九成是后端没起。看终端 1 是否报错，或直接访问 http://127.0.0.1:5112/api/v1/health 应返回 `up`。

**Q：删除了公司，投递记录还在吗？**
在。投递是独立记录，公司删除只影响公司档案本身。

**Q：改了状态但时间线没多出事件？**
不会发生——所有变更都自动留痕。如果你发现缺失，告诉我排查。

**Q：CSV 导出乱码？**
不会。导出已带 UTF-8 BOM，Excel 直接打开中文正常。

**Q：想自己改数据？**
可以，页面上的增删改都真实生效（改完状态自动留痕）。改完告诉我一声，我同步本地归档文件夹。

## 六、约定与边界

- 归档文件夹（`后端开发/公司名/投递N_日期/`）与系统记录由我保持同步
- 简历修改基于事实，**不编造数据**（无量化数据用免数字改写）
- 秋招期间时间一律按杭州时间（GMT+8）
- 本系统为本地单人系统，无账号权限概念；不要把 5111/5112 端口暴露到公网
