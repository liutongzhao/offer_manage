# 文档索引

> 本目录是「秋招投递管理系统」的全部设计与开发文档，按阅读与使用顺序分四类收纳。
> 命名遵循 ADR-003：文档/说明用中文，代码标识符用英文。

## 目录结构

| 目录 | 内容 | 阅读顺序 |
| --- | --- | --- |
| `01-需求/` | 需求规格说明书（唯一需求来源，含需求编号与状态标记） | 1 |
| `02-架构/` | 系统架构设计与长期演进规划 | 2 |
| `03-UI设计/` | 界面设计方案（设计令牌唯一来源）、UI 设计稿与落地手册（页面级设计稿）、高保真原型（可点击 HTML） | 3 |
| `04-运行/` | 运行说明（启动方式、端口、环境坑位） | 开发/部署时查阅 |
| `05-部署/` | 云服务器部署指南（Docker Compose、数据迁移、备份恢复、HTTPS 升级） | 部署时查阅 |

## 文档清单

- **`01-需求/需求规格说明书.md`**（v1.1）——功能需求编号 `REQ-{模块}-{序号}`，按优先级 12 批全部实现；变更留痕、沟通记录等核心决策已拍板。
- **`02-架构/架构设计.md`**——分层架构（Vue / FastAPI / SQLite / MinIO）、模块职责、数据模型、开发规范、ADR 决策记录。
- **`03-UI设计/界面设计方案.md`**（v1.0）——设计令牌（配色/字号/圆角/阴影/间距/栅格）、组件与状态定义、交互与动效、响应式规则。
- **`03-UI设计/UI设计稿与落地手册.md`**（v1.0）——18 个设计物件全景、逐页线框到高保真、边界场景处理、Figma/设计工具落地规范。
- **`03-UI设计/高保真原型.html`**——单文件可点击原型，桌面 1440 与移动 375 断点，5 种列表状态演示。浏览器直接打开即可。
- **`04-运行/运行说明.md`**——本地启动步骤、端口（前端 5111 / 后端 5112）、MinIO 与数据库说明、本环境已知坑位。
- **`04-运行/用户使用指南.md`**——面向使用者的功能介绍：对话下单流程、9 个页面详解、数据安全、常见问题。
- **`05-部署/部署指南.md`**——云服务器部署全流程：端口规划与安全组、配置生成、本地数据迁移、启动验证、日常发版、备份恢复、HTTPS 升级路径。配套编排文件在 `投递管理系统/deploy/`。

## 维护约定

1. 新增文档先归入对应分类目录，再更新本索引。
2. 需求变更只改 `需求规格说明书.md` 并在 §8 变更记录追加，不新开文档。
3. 设计令牌只以 `界面设计方案.md` §2 为唯一来源，其他文档引用不复制。
